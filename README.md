# DESARROLLO-DE-SOFTWARE-PARAPLATAFORMAS-MOVILES

Aplicación de contactos hecha con React, convertida en PWA (Progressive Web App) para poder instalarse en el celular.

## Demo en vivo desplegada en render

[Ver aplicación desplegada](https://desarrollo-de-software-paraplataformas.onrender.com/)

## Funcionalidades

- Loader inicial con cuenta regresiva
- Listar contactos (nombre y teléfono)
- Agregar nuevos contactos
- Eliminar contactos
- Funciona offline gracias al Service Worker (Hybrid Strategy)
- Instalable como app en el celular (PWA)

## Cómo instalar la PWA en el celular

### Android (Chrome)

1. Abre el link de la aplicación en Chrome: [https://desarrollo-de-software-paraplataformas.onrender.com/](https://desarrollo-de-software-paraplataformas.onrender.com/)
2. Toca el menú de tres puntos (⋮) en la esquina superior derecha.
3. Selecciona la opción **"Instalar aplicación"** o **"Agregar a pantalla de inicio"**.
4. Confirma la instalación. El ícono de la app aparecerá en tu pantalla de inicio.
5. Al abrirla, funcionará como una app nativa, incluso mostrando contenido cuando no tengas conexión a internet.
