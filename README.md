# DESARROLLO-DE-SOFTWARE-PARAPLATAFORMAS-MOVILES

## Challenge 04 - Login y Rutas en Contactos (Ionic + React + TypeScript)

Aplicación de gestión de contactos construida con Ionic, React y TypeScript. Incluye un sistema de autenticación con persistencia de sesión, y rutas dinámicas para crear contactos y ver sus detalles.

## Cómo correr el proyecto

El proyecto de Ionic se encuentra dentro de la carpeta `contactos/`.

1. Clona el repositorio y cámbiate a la rama `challenge04`:

```bash
   git checkout challenge04
```

2. Entra a la carpeta del proyecto:

```bash
   cd contactos
```

3. Instala las dependencias:

```bash
   npm install
```

4. Levanta el servidor de desarrollo:

```bash
   ionic serve
```

5. La app se abrirá automáticamente en el navegador en `http://localhost:8100`. Ingresa con las credenciales de prueba indicadas arriba.
