# DESARROLLO-DE-SOFTWARE-PARAPLATAFORMAS-MOVILES

## Challenge 03 - Task Manager (Ionic + React + TypeScript)

Aplicación de gestión de tareas construida con Ionic, React y TypeScript. Permite ver una lista de tareas pendientes y completadas, agregar nuevas tareas, marcarlas como completadas y eliminarlas.

## Cómo correr el proyecto

El proyecto de Ionic se encuentra dentro de la carpeta `task/`.

1. Clona el repositorio y cámbiate a la rama `Challenge03`:

```bash
   git checkout Challenge03
```

2. Entra a la carpeta del proyecto:

```bash
   cd task
```

3. Instala las dependencias:

```bash
   npm install
```

4. Levanta el servidor de desarrollo:

```bash
   ionic serve
```

5. La app se abrirá automáticamente en el navegador en `http://localhost:8100`
